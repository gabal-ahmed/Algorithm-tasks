# Algorithm Tasks

My solutions for the algorithms tasks. Each task has its own folder with the code and a README.

| # | Task | Files |
|---|---|---|
| 1 | [Insertion sort analysis](task-1) | `insertion_sort.py`, `experiment.py`, `REPORT.md` |
| 2 | [Sorting benchmark](task-2) | `benchmark.py`, `benchmark_plot.png` |
| 3 | [OS task scheduler (max heap)](task-3) | `task_scheduler.py` |
| 4 | [Island counter (BFS / DFS)](task-4) | `island_counter.py` |

## Setup
```
pip install -r requirements.txt
```
Then go into any task folder and run the python file, for example:
```
cd task-1
python experiment.py
```

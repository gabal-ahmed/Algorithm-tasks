# Task 1 - Insertion Sort analysis

Insertion sort that also counts how many comparisons and shifts it does, then an experiment that runs it on sorted, random and reversed lists for n from 100 to 5000 and compares the times with merge sort.

Files:
- `insertion_sort.py` - the sort, returns `(list, comparisons, shifts)`
- `experiment.py` - runs the tests, prints a table and saves the graph in `plots/`
- `REPORT.md` - what I got and what it means

Run:
```
python insertion_sort.py
python experiment.py
```
